## 🍔 Kuisine Eats – Food Ordering & Delivery App

Kuisine Eats is a visually stunning food ordering app designed for a fast food restaurant.  
Users can browse menus, place orders, await delivery and enjoy a smooth checkout experience — all in one app.

### 🚀 Features
- Browse and order meals (pizza, tacos, drinks, snacks, burgers, etc.)  
- Table reservations and food pick-up options  
- Secure and fast checkout system  
- Clean, modern UI/UX focused on customer experience  

### 🛠️ Tech Stack
- **React Native** (cross-platform mobile development)  
- **Firebase** (authentication & backend services)  
- **Stripe/Paystack** (payment integration)
